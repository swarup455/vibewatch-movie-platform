# VibeWatch

VibeWatch is an AI-powered movie recommendation platform that helps users discover movies tailored to their interests. The platform combines an intelligent recommendation chatbot, a smart discovery engine, and personalized collections to create a seamless movie exploration experience.

## Features

- AI-powered movie recommendation chatbot
- Smart movie discovery and search
- Personalized movie recommendations
- Custom watchlists and collections
- Modern and responsive user interface

## Tech Stack

- Next.js
- TypeScript
- Tailwind CSS
- shadcn/ui
- AI/LLM Integration

## Installation

### Clone the Repository

```bash
git clone https://github.com/your-username/vibewatch.git
cd vibewatch
```

### Install Dependencies

```bash
npm install
```

### Run the Development Server

```bash
npm run dev
```

Open http://localhost:3000 in your browser.
